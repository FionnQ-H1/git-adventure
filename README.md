# Git Adventure

A "Choose Your Own Adventure" story written by everyone at the ATU Software Development Society Git & GitHub workshop.

Every scene is its own file. Every choice is a link to another scene. You add to the story the same way you'll work on a real group project: on a branch, through a Pull Request.

**Start reading here: [start.md](start.md)**

## How the story works

- The story begins in `start.md`.
- Every other scene lives in the `scenes/` folder, one file per scene.
- Each scene ends with 2 or 3 choices. A choice is a link to another scene file.
- A choice marked *(not written yet)* points to a scene nobody has written. Pick one and write it.

## Rules

1. **One scene per file.** Name it in lowercase with hyphens, e.g. `scenes/fight-the-printer.md`.
2. **Start from the template.** Copy `scenes/TEMPLATE.md` so every scene looks the same.
3. **Every scene needs a way forward.** End with at least two choices, or a clear THE END.
4. **Never work on `main`.** Make your own branch. `main` is protected, so changes only get in through a Pull Request.
5. **Keep it clean.** Funny is good. Anything you wouldn't say in front of your lecturer is not.
